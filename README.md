# Top No-Code Custom Data Modeling Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual Schema Design, Relational Data Structuring & No-Code Application Building*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **No-Code Custom Data Modeling Tools**. These tools let users define custom data structures, relationships, and views through visual interfaces — spreadsheet-like grids, drag-and-drop schema designers, and form builders — without writing SQL or application code.

**Examples** include Salesforce Lightning Object Creator, Airtable, Notion Databases, Coda, Quickbase, Knack, Caspio, Smartsheet, Kintone, and Baserow (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom data model ownership, and transparent schema management — ideal for teams prioritizing data sovereignty, developers building internal tools, and organizations seeking Airtable alternatives without vendor lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Lightning Object Creator](https://www.salesforce.com/)**  
  No-code tool for creating custom objects, fields, and relationships within Salesforce with automatic page layouts and permissions.

- **[Airtable](https://airtable.com/)**  
  Spreadsheet-database hybrid for building custom applications with flexible fields, linked records, and multiple view types.

- **[Notion Databases](https://www.notion.so/)**  
  Flexible database system within Notion for organizing content, projects, and knowledge with relations, rollups, and multiple views.

- **[Coda](https://coda.io/)**  
  All-in-one doc platform with tables, formulas, buttons, and automations for building custom team tools and workflows.

- **[Quickbase](https://www.quickbase.com/)**  
  No-code platform for building custom business applications with relational databases, forms, and workflow automation.

- **[Knack](https://www.knack.com/)**  
  No-code application builder with database backend, drag-and-drop interface, and role-based access for business apps.

- **[Caspio](https://www.caspio.com/)**  
  No-code platform for building database-driven applications with forms, reports, and workflows on a managed cloud database.

- **[Smartsheet](https://www.smartsheet.com/)**  
  Work management platform with spreadsheet-like interface, customizable columns, and automated workflows.

- **[Kintone](https://www.kintone.com/)**  
  No-code application platform with customizable databases, forms, and workflow automation for team collaboration.

- **[Baserow](https://baserow.io/)**  
  Open-source no-code database and application builder with spreadsheet-like interface, automations, and API-first architecture.

## Open-Source GitHub Projects

- **[NocoDB](https://github.com/nocodb/nocodb)**  
  The fastest and easiest way to build databases online. Turns any SQL database into a smart spreadsheet with grid, kanban, gallery, form, and calendar views. Self-hosted alternative to Airtable. [citation:8][citation:11]

- **[Baserow](https://github.com/baserow/baserow)**  
  Secure, open-source no-code platform for building databases, applications, automations, and AI agents. Trusted by 150,000+ users with GDPR, HIPAA, and SOC 2 Type II compliance. MIT licensed. [citation:7][citation:13]

- **[Teable](https://github.com/teableio/teable)**  
  Next-gen Airtable alternative built on PostgreSQL. Spreadsheet-like interface supporting millions of rows with real-time collaboration, multiple views (grid, form, kanban, gallery, calendar), and plugin system. AGPL-3.0 licensed. [citation:5]

- **[Saltcorn](https://github.com/saltcorn/saltcorn)**  
  Extensible no-code database application builder for web and mobile apps. Features visual table designer, flexible views, layouts, actions, and plugin system. Supports PostgreSQL and SQLite backends. MIT licensed. [citation:3][citation:18]

- **[Sovrium](https://github.com/sovrium/sovrium)**  
  Configuration-driven web application platform. One config file creates database, REST API, authentication, and pages. Self-hosted alternative to Airtable, Retool, and Notion with 49 field types and Git-native version control. [citation:1][citation:4]

- **[d9 (Datos Online)](https://github.com/Datos-Online/d9)**  
  Open Data Platform that democratizes database access. Links to any SQL database, performs CRUD operations, builds complex queries, and generates REST/GraphQL APIs. No vendor lock-in — remove anytime without affecting data model. [citation:2]

- **[NocoBase](https://github.com/nocobase/nocobase)**  
  Extensible no-code/low-code platform for building business applications. Database-backed with pages, forms, roles, workflows, and plugin ecosystem. Self-hosted with MySQL, MariaDB, or PostgreSQL. [citation:15]

- **[undb](https://github.com/undb-xyz/undb)**  
  Private-first, unified, self-hosted no-code database. Lightweight (requires just one file storage by default), with Power BI-like record level security, multiple views (grid, kanban, gantt, tree, calendar), OpenAPI, and webhooks. AGPL-3.0 licensed. [citation:17]

- **[Directus](https://github.com/directus/directus)**  
  Real-time API and App dashboard for managing SQL database content. Wraps any SQL database with a no-code data studio, REST and GraphQL APIs, and granular access control. [citation:2][citation:12]

- **[pgkiln](https://github.com/pgkiln/pgkiln)**  
  Low-code, SQL-driven application builder for PostgreSQL, modeled on Oracle APEX. Applications are data: pages, regions, items, and processes are rows in a meta schema. Includes MCP server for AI coding agents. [citation:9]

- **[Mathesar](https://github.com/mathesar-foundation/mathesar)**  
  Spreadsheet-like tool for PostgreSQL data. No-code database manager and PostgreSQL GUI providing visual interface for managing relational data. [citation:12]

- **[Grist](https://github.com/gristlabs/grist-core)**  
  Modern relational spreadsheet combining spreadsheet flexibility with database structure. Python formulas, access controls, and self-hostable. [citation:12]

### Additional Strong Open-Source Options

- **[Appsmith](https://github.com/appsmithorg/appsmith)** — Open-source low-code platform for building internal tools with database connectors, widgets, and workflow triggers.
- **[ToolJet](https://github.com/ToolJet/ToolJet)** — Open-source low-code platform with visual app builder and 50+ data source connectors.
- **[Budibase](https://github.com/Budibase/budibase)** — Open-source low-code platform with built-in database, automation engine, and form builder.
- **[API Platform](https://github.com/api-platform/api-platform)** — Open-source framework for building hypermedia APIs from custom data models.
- **[Supabase](https://github.com/supabase/supabase)** — Open-source Firebase alternative with Postgres database, auto-generated APIs, and real-time subscriptions.
- **Database Schema Tools** — Prisma, Drizzle, and TypeORM for code-first schema definition with visual tools.
- **Spreadsheet Libraries** — Luckysheet, Handsontable, and x-spreadsheet for building custom spreadsheet interfaces.

**Frameworks for building custom systems**: Combine **NocoDB** or **Baserow** for the no-code data layer, **Directus** for API generation, **Saltcorn** for application building, and **PostgreSQL + Metabase** for analytics to build a complete self-hosted data modeling stack.
